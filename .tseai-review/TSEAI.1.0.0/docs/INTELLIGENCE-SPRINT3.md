# Intelligence Sprint 3 — Multi-facet grounded answers

این اسپرینت شکاف سؤال‌های چندبخشی را می‌بندد. پیش از این، نخستین پاسخ کامل SQL باعث پایان زودهنگام درخواست می‌شد و بخش‌های مستقل سؤال مانند «مدیرعامل + قیمت» یا «نام شرکت + P/E» حذف می‌شدند.

## تغییرات اصلی

- تحلیل قطعی facetهای مستقل پیش از بازگشت پاسخ canonical؛
- اجرای هم‌زمان پاسخ مرجع SQL و Snapshot بازار برای سؤال ترکیبی؛
- حفظ پاسخ معتبر یک facet در صورت نبود یا رد کیفیت facet دیگر؛
- محدودکردن «آخرین خبر نماد» به همان نماد در Qdrant؛
- جلوگیری از جایگزینی خبر کلی بازار با خبر نماد؛
- پشتیبانی از «نمادش» در سؤال آخرین عرضه اولیه و بازگرداندن نام، تاریخ شمسی و نماد؛
- جلوگیری از افتادن سؤال مدیرعامل شرکت در مسیر مدیرعامل بورس تهران؛
- پاسخ fail-closed و صریح در صورت نبود رکورد Companystate؛
- ثبت Tool مستقل `answer.compose.composite` و کنترل Evidence/Validation نهایی.

## معیار پذیرش

- Build API بدون Warning و Error؛
- پاس‌شدن ۱۱۷ تست Python؛
- پاس‌شدن ۱۴ از ۱۴ پروژه Smoke دات‌نت؛
- نسخه ۱.۲ مجموعه مکالمه طلایی با حداقل ۲۲ نوبت؛
- نبود Planner و synthesis آزاد در پاسخ‌های canonical-market؛
- Grounded بودن Answer Validation و نمایش فقط تاریخ شمسی.
